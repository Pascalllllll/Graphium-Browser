# Security policy

## Supported versions

Only the latest release gets security fixes. Graphium has no automatic
updater, so please update from the
[Releases page](https://github.com/Pascalllllll/Graphium-Browser/releases/latest).

## Reporting a problem

Please **don't** open a public issue for a security problem. Instead, use
GitHub's private reporting: open the repository's **Security** tab and click
**Report a vulnerability**.

Include what you found, the steps to reproduce it, and the Graphium version
(shown at the bottom of Menu → Settings). You'll get an answer within 7 days.

Bugs in Chromium itself should go to the
[Chromium bug tracker](https://issues.chromium.org); Graphium picks up the fix
in the next release built on a newer Electron.
